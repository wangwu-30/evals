# WritingBench

| 字段 | 内容 |
|---|---|
| 名称 | WritingBench |
| 类型 | 评测集 |
| 评什么 | 开放式写作与逐题标准 |
| 适用场景 | 报告、改写、长文；适配中高 |
| 短板 | 动态评分表增加变量；语言比例、第三方素材权利未逐项核实 |
| 规模与许可 | **已核仓库：1,000 查询、6 大领域、100 子领域；仓库 Apache-2.0**；每题固定 5 项本轮未核实 |
| 是否采用及理由 | 按领域抽 100–200 项作工程子集；冻结逐题评分表，中文覆盖另计 |
| 来源链接 | [仓库](https://github.com/X-PLUG/WritingBench)、[许可证](https://raw.githubusercontent.com/X-PLUG/WritingBench/main/LICENSE)、[论文](https://arxiv.org/abs/2503.05244) |
